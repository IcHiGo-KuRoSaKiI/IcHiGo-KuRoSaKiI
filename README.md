## `// whoami`

I'm **Vedansh** — a **Developer & Solution Architect** from India, focused on **Generative AI** and the systems around it. I've also been building games since long before it was a job.

What I care about most is **architecture** — designing the whole system (data, services, infra, and how the AI actually fits) instead of just wiring a model into an app.

**What I work on**
- 💡 **Generative AI & LLMs** — RAG pipelines, LLM-powered products, and **MCP servers** that connect real tools to models
- 🏗️ **Solution architecture** — end-to-end system design across backend, cloud and data
- 📊 **Applied ML** — document intelligence and finance / BFSI models, fine-tuning & small language models
- 🎮 **Game dev** — Unity / C# multiplayer and agent-driven simulations

**A few things I'm proud of**
- 🏆 Won **Toyacathon 2021** with a Unity game built on Indian mythology
- 🛡️ Built a **multiplayer CTF emulator** for an international cybersecurity event (CIACON)
- 🤟 Built an **Indian Sign Language interpreter** (2019), showcased at the Innovation Punjab Summit
